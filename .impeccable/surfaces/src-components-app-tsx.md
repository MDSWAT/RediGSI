## Scoped platform patterns

Point clustering is a map toolbar choice with a visible pressed state. Layer-colored count circles expand geographically and expose all coincident members in a scrollable popup paginated by 20. Selecting a member retains its original popup and community details, including approximate-location and provenance text; returning to the group does not merge records or invent precision.

Geometry editing creates a separate teal draft layer. A wrapping white floating toolbar names the task, explains explicit saving and exposes Anulează / Salvează, busy state and an inline failure. Points use a 44px drag target; line/polygon vertices can be adjusted. Cancel discards the draft; save checks the prior geometry and retains audit history. GPS correction reuses the native dialog, with manual WGS84 fields and a collapsed optional address search. Only an organization-configured provider is named; consent and an explicit search action precede transmission. Result selection fills the fields, followed by a separate save.

Publication review uses required privacy review and separate initially unchecked public-visibility/exact-geometry controls. It publishes the reviewed base-field snapshot; later edits require administrator republication. The classification manager reuses member list/detail forms with active/archived states and save/error feedback. Active names can be public suggestions, while descriptions stay internal and historical values are preserved.

Data adds accessible import-batch summary tables, KML and probable-duplicate review. Exclusion is opt-in; interrupted imports report only rows confirmed by the server. Analytics extends existing flat report sections with demographic source ranges, registry outreach, sector/partner drill-through and currency-separated sums. Unknown-currency values are explicitly excluded, and the unspecified-sector bar cannot drill through. Registry outreach is not a claim about total market penetration.
